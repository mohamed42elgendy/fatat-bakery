## 📌 عن المشروع (Project Overview)
نظام تشغيلي متطور صُمم خصيصاً لمصانع وسلاسل المخابز والحلويات (مصنع مخبوزات فتات)، يربط دورة التشغيل الكاملة لحظياً بحساب الأرباح والخسائر (Live P&L):
1. **استلام الخامات بالذكاء الاصطناعي (Smart Vision AI / OCR):** قراءة صور الكراتين والأكياس وتواريخ الصلاحية آلياً مع مطابقة ذكية بقائمة الأصناف القياسية (Master Catalog) لمنع تكرار الأقسام أو تشويه الداتا.
2. **صمام الأمان والاعتماد الفوري (Safety Confirmation Gate):** مراجعة بصرية سريعة بلمسة واحدة قبل قيد الخامات في المستودع.
3. **صرف الخامات لخطوط الإنتاج (Production Issue Tracking):** تتبع استهلاك خطوط إنتاج الكرواسون، الخبز، المعمول، والباتيه مع احتساب تكلفة البضاعة المباعة (Food Cost / COGS) بنظام الوارد أولاً يصرف أولاً (FIFO).
4. **شجرة الأصناف المعتمدة للمصانع:** (دقيق فاخر 72%، زبدة نيوزيلندي، خميرة فورية، شوكولاتة بلجيكي، سكر، وغيرها).
5. **مستويات صلاحيات تشغيلية دقيقة (RBAC):**
   - 👑 **مستر محمد الجندي (مدير تشغيل إقليمي):** تحكم وصلاحيات تنفيذية وتصفير كامل.
   - 👁️ **المالك / Owner:** لوحات متابعة وقوائم مالية للقراءة فقط بدون تعديل.
   - 📦 **أمين المستودع:** شاشة الكاميرا والباركود واستلام وصرف المواد.
   - 🧾 **مسؤول الحسابات والنثريات:** تسجيل الفواتير والمصروفات.
6. **تطبيق ويب تقدمي (PWA):** يعمل كتطبيق أصيل على هواتف آيفون (iOS) وأندرويد (Android) بدون الحاجة لمتجر تطبيقات، ويعمل حتى بدون إنترنت (Offline Caching).

## 📲 تثبيت النظام كتطبيق على الهواتف (PWA Mobile Installation)

### 🍏 على هواتف آيفون (iPhone / Safari):
1. افتح رابط النظام في متصفح **Safari**.
2. اضغط على زر **المشاركة (Share)** أسفل الشاشة.
3. اختر **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)**.
4. اضغط **"إضافة" (Add)**. سيظهر أيقونة التطبيق الذهبية على شاشة هاتفك فوراً.

### 🤖 على هواتف أندرويد (Android / Chrome):
1. افتح رابط النظام في متصفح **Google Chrome**.
2. ستظهر لك رسالة تلقائية أسفل الشاشة: **"تثبيت تطبيق مخبوزات فتات"**، اضغط **"تثبيت"**.
3. أو اضغط على القائمة (⋮) ثم اختر **"تثبيت التطبيق" (Install App)**.

## 🚀 تشغيل النظام عبر GitHub Pages مجاناً وبثوانٍ

1. قم بإنشاء مستودع جديد على حسابك في GitHub (مثلاً: `fatat-bakery`).
2. ارفع محتويات هذا المجلد:
   - `index.html`
   - `manifest.json`
   - `service-worker.js`
   - `icon-192.png`
   - `icon-512.png`
3. من صفحة المستودع: اذهب إلى **Settings** ⚙️ ➔ **Pages** ➔ اختر الفرع **main** أو **master** والمسار **/(root)** ثم اضغط **Save**.
4. خلال دقيقة واحدة، سيمنحك GitHub رابطاً عالمياً يعمل عبر بروتوكول HTTPS الآمن:
   `https://<your-username>.github.io/fatat-bakery/`
